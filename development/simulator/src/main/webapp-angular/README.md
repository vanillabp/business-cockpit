# Simulator user interface, Angular

The Angular user interface of the [simulator](../../..), next to the React one. It exists so that
both dev shells are exercised by something which is really built, and it is what a change to
[dev-shell-angular](../../../../dev-shell-angular) is verified against.

The workflow module side of all this is in the wiki, under
[User task forms and status sites](https://github.com/vanillabp/business-cockpit/wiki/User-task-forms-and-status-sites).
It is built by the Maven module above it; `npm start` runs the dev server.
