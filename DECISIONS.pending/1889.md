# The BPMS API takes the path of its sender from the server URL of its specification

**Status:** decided, 2026-11-18, story 1889. It follows the decision about client groups which
are there only with their address (story 1887), which made the same rule for the official GUI API.

**Context.** The REST transport of the extension added a path written by hand, `/bpms/api/v1_1`,
to `vanillabp.cockpit.rest.base-url`. The server URL of the specification was `/api/v1_1`, and
the `/bpms` in front of it was known only to the cockpit and to that constant. A new version of
the API meant a new dependency and a changed constant, and nothing tied the two together.

**Decision.**

- The server URL of both specifications of the BPMS API is the full path below the address of
  the cockpit: `/bpms/api/v1` and `/bpms/api/v1_1`. The generated server interfaces do not carry
  the server URL, so they stay exactly as they were. Only the default `basePath` of the generated
  `ApiClient` changes, which every sender replaces anyway.
- `bpms-api-client` generates `BpmsApiPath.PATH` from the server URL with a template of its own,
  `apis/bpms-api/client/generator/ApiPath.mustache`, registered in `generator/config.yaml`. No
  template of the generator is copied.
- The REST transport adds `BpmsApiPath.PATH` to `base-url`. The constant written by hand is gone.
- A `base-url` which ends with the path stops the start with a message that names the address
  without it. Without the check every report would go to `/bpms/api/v1_1/bpms/api/v1_1/...` and
  the mistake would show only as a 404 at the first report.
- The simulator of `development/simulator` follows the same rule for its own key
  `application.business-cockpit.base-url`.

**Compatibility.** `vanillabp.cockpit.rest.base-url` keeps its meaning of version 1: the address
of the cockpit, to which the transport adds the path. Version 1 added `/bpms/api/v1_1` the same
way, so a value of version 1 works unchanged. The new check refuses only a value which never
worked, because it holds the path twice once the path is added.
