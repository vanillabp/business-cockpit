# Where to look

*Part of the description in [`../SKILL.md`](../SKILL.md).*

This skill does not copy the API files, the README files or the wiki. A copy goes out of date, and
it fills the context of every agent. The skill points to the source instead, and it writes down a
rule only where the source leaves a choice open.

So before you write a question into `plan/QUESTIONS-DRAFT.md`, look it up here first, see
[Questions never block](working-in-stories.md#questions-never-block). Read the source at the version
the project pins: the cockpit at `Q-COCKPIT-VERSION`, the VanillaBP kit at the version the module
kit covers. For a snapshot, read the branch `main`.
